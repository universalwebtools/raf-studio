# RAF.studio v3
GitHub Pages + Firebase Realtime Database + Firebase Storage.

Funkcje v3: synchronizacja ustawień przez Firebase, masowy upload ze wskaźnikiem postępu, drag&drop portfolio, masowe operacje, kadrowanie i rozmiary osobno dla PC/Tablet/Telefon, sticky mobile dock, lightbox, integracja galerii klienta oraz panel diagnostyczny.

## Zapis online
Panel admina nie wymusza teraz logowania. Bezpieczny zapis do Firebase działa, gdy w tej samej domenie istnieje aktywna sesja administratora Firebase (np. po zalogowaniu w panelu raf.studio.galeria). W przeciwnym razie panel zachowuje lokalny backup i pokazuje status zamiast fałszywego sukcesu.
